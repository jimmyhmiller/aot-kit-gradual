## Graph semantics

- Solid edges are concrete specification-operation or explicitly reviewed item dependencies.
- Dashed edges are aggregate capability prerequisites. They describe milestone debt but must not hide which concrete operation can be implemented next.
- `concreteReady` means an incomplete item has no known incomplete concrete prerequisite. It does not mean the item is implemented.
- `soleRemainingConcreteDependency` counts direct dependents for which one candidate is the last incomplete concrete prerequisite.
